# Evaluación sumativa 1 y 2

## Problema preparado

Dados una distancia, un rendimiento y un precio, calcular los litros usados y el costo total

Problem number: [TBD]

## Datos

- `D` representa la distancia y es una variable de tipo entero
- `R` representa el rendimiento y es una variable de tipo entero
- `P` representa el precio y es una variable de tipo entero
- `LITROS` y `COSTO` almacenan los resultados y son variables de tipo entero

El cálculo supone que `R` es diferente de cero. Como las variables son enteras, las operaciones usan división entera

## Fórmulas

- `LITROS <- D / R`
- `COSTO <- LITROS * P`
