## Función selectiva múltiple

Dados `NUM` y `V`, obtener el valor de `VAL` según la opción seleccionada

## Casos

- `NUM = 1` devuelve `100 * V`
- `NUM = 2` devuelve `100 ** V`
- `NUM = 3` devuelve `100 / V`
- Cualquier otro valor devuelve `0`
